terminal-sharks 螢幕保護程式 安裝說明
==========================================

電腦閒置時自動出現，移動滑鼠或按任意鍵就會關閉。有兩個場景可以選：
- 鯊魚海洋：ASCII 鯊魚在黑色海洋裡游動（預設）
- 宇宙：藍咩與航星者在像素風的夜空裡飄來飄去
切換方法見下面〈切換場景〉。


■ 需要的環境
------------------------------------------
- Windows 10 或 Windows 11（64 位元）
- Microsoft Edge WebView2 Runtime
  Windows 11 已內建；Windows 10 有在更新的通常也有。
  如果打開後是白畫面或沒有反應，請見最下面〈常見問題〉。


■ 安裝步驟
------------------------------------------
1. 解除封鎖（很重要，請在解壓縮「之前」做）
   對下載的 terminal-sharks.zip 按右鍵 →「內容」
   → 勾選最下面的「解除封鎖」→ 按「確定」。
   ※ 沒有這個選項，代表檔案沒被封鎖，直接下一步即可。

2. 解壓縮
   對 zip 按右鍵 →「全部解壓縮」。

3. 把 terminal-sharks.scr 放到固定的位置
   例如 C:\Tools\terminal-sharks.scr
   ※ 不要留在「下載」資料夾，也不要直接從 zip 裡執行。
     安裝後 Windows 只記住檔案位置，檔案被搬走或刪掉就會失效。

4. 測試
   對 terminal-sharks.scr 按右鍵 →「測試」。
   畫面會變成全螢幕的鯊魚，動一下滑鼠就會結束。
   第一次可能會出現「Windows 已保護您的電腦」，
   請按「其他資訊」→「仍要執行」。

5. 安裝
   對 terminal-sharks.scr 按右鍵 →「安裝」。
   會打開「螢幕保護程式設定」，並已選好 terminal-sharks。
   設定「等候」幾分鐘後啟動 → 按「確定」。
   ※ 視窗裡的小預覽畫面是黑的，這是正常的，不影響使用。


■ 切換場景
------------------------------------------
預設是「鯊魚海洋」。想換成「宇宙：藍咩與航星者」或換回來：

1. 打開設定視窗，以下任一種方法都可以：
   - 對 terminal-sharks.scr 按右鍵 →「設定」
   - 直接對 terminal-sharks.scr 按兩下
   - 在「螢幕保護程式設定」（設定 → 個人化 → 鎖定畫面 → 螢幕保護程式）
     選好 terminal-sharks 後，按右邊的「設定」按鈕
2. 會出現「terminal-sharks 設定」小視窗，
   點選「鯊魚海洋」或「宇宙：藍咩與航星者」。
3. 下方出現「已儲存：…」就完成了，直接關掉小視窗即可，不用按確定。
4. 想先看看效果：對 terminal-sharks.scr 按右鍵 →「測試」。

※ 下次螢保啟動時就會是新選的場景，不用重新安裝。
※ 設定是每個 Windows 使用者各自記住的；換一個帳號登入要重新選一次。
※ 出現「無法儲存設定」時，請關掉視窗再試一次。


■ 用快捷鍵隨時叫出來（可選）
------------------------------------------
1. 在桌面空白處按右鍵 →「新增」→「捷徑」。
2. 位置輸入（含引號與最後的 /s，路徑換成你放的位置）：
   "C:\Tools\terminal-sharks.scr" /s
3. 取個名字 →「完成」。
4. 對捷徑按右鍵 →「內容」→ 點「快速鍵」欄位 → 按一個字母（例如 S），
   會變成 Ctrl + Alt + S → 按「確定」。

※ 捷徑必須放在「桌面最外層」或「開始功能表」才有效，
  放在桌面上的資料夾裡不行。
  想收起來：按 Win + R 輸入 shell:programs，把捷徑搬進去（可建子資料夾）。


■ 解除安裝
------------------------------------------
1. 開啟「螢幕保護程式設定」（設定 → 個人化 → 鎖定畫面 → 螢幕保護程式），
   選「(無)」→「確定」。
2. 刪除 terminal-sharks.scr 和你建立的捷徑。


■ 常見問題
------------------------------------------
Q. 等待時間到了，螢保沒有出現？
A. 多半是沒有「解除封鎖」。對 terminal-sharks.scr 按右鍵 →「內容」
   → 勾選「解除封鎖」→「確定」，再重新「安裝」一次。

Q. 打開後是白畫面，或完全沒反應？
A. 缺少 WebView2 Runtime。到微軟官網搜尋「WebView2 Runtime」，
   下載「Evergreen Bootstrapper」安裝後再試：
   https://developer.microsoft.com/microsoft-edge/webview2/

Q. 防毒軟體把它刪掉或擋下來？
A. 這個程式沒有數位簽章，部分防毒會誤判。公司電腦請先詢問 IT 是否允許安裝。

Q. 畫面關不掉？
A. 按 Ctrl + Alt + Delete →「工作管理員」→ 找到 terminal-sharks → 結束工作。

Q. 按快捷鍵後畫面一閃就關掉？
A. 按下快捷鍵後請馬上放開按鍵。仍然發生的話請回報給提供檔案的人。
