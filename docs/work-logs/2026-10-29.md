# 2026-10-29 工作紀錄 — terminal-sharks 做成 Windows 螢幕保護程式(.scr)

原本要開終端機 `npm start` 才看得到鯊魚，實用性不夠。目標：雙擊或閒置就能看，之後能換成自己畫的生物。

## 決策

- Windows 對應 exe；最後做成 **`.scr` 螢幕保護程式**(`.scr` 就是改副檔名的 exe)。
- 外殼用 **Tauri 2**(Rust + 系統內建 WebView2)，成品約 5.7 MB。不選 Electron(100MB+)、不選「終端機版打包 exe」(仍是主控台視窗)。
- 上游本來就是網頁 canvas：`AsciiRenderer` 直接畫在真的 `<canvas>`，模擬與繪製程式不用改；`term.ts` 的假 context 只是終端機版在用。
- 快捷鍵不寫程式：Windows 捷徑的「快速鍵」欄位指向 `terminal-sharks.scr /s`。
- 自己的角色：做成另一個場景「宇宙：藍咩與航星者」(見〈宇宙場景〉)。

## 如何測試

1. 瀏覽器版：`npm run dev` → 開 `http://localhost:5173`，鯊魚在游、滑鼠會引誘魚群、點擊濺水花、縮放視窗正常。
2. 終端機版回歸：`npm start`、`npm start -- tiger:dark,mako`，跟改之前一樣；`npm start -- tiger:xxx` 要印出 Unknown shade 並結束。
3. `.scr` 右鍵「測試」：
   - 全螢幕、看得到鯊魚、游標隱藏。
   - 按任一鍵 / 點擊 / 明顯移動滑鼠 → 結束；輕微晃動(<10px)不結束。
   - 多螢幕時每個螢幕都有畫面，任一個螢幕收到輸入就全部結束。
4. 雙擊 `.scr` → 出現「目前沒有設定項目」小視窗。
5. 右鍵「安裝」→ 螢幕保護程式設定已選好它(小預覽框是黑的，預期如此)→ 等待時間設 1 分鐘，放著不動等它自己出現。
6. 捷徑快捷鍵：桌面捷徑目標 `"D:\side\terminal-sharks\release\terminal-sharks.scr" /s`，內容裡設「快速鍵」(例 Ctrl+Alt+S)，按下會直接進螢保。
   - 快速鍵只對「桌面最外層」或「開始功能表(含子資料夾)」的捷徑有效；桌面上的資料夾裡不行。想收起來就放 `shell:programs` 底下的子資料夾。
   - 右鍵「安裝」不會複製 `.scr`，Windows 記的是 `release/` 裡的原路徑，不要搬動或刪除；重跑 `npm run scr` 覆蓋同一位置沒關係。
7. 別台 Windows：只帶 `.scr` 過去(壓成 zip，Email 常擋 `.scr`)，確認 SmartScreen 警告後能跑；最好挑一台沒有開發環境的，順便確認 VC++ runtime 不用另外裝。

關不掉時：Ctrl+Alt+Del → 工作管理員結束 `terminal-sharks.scr`。

若測試失敗，先用開發模式看錯誤：`npm run tauri dev -- -- /s`(會開 Vite 與 debug 版視窗，可在視窗按 F12 開 DevTools)。

## 重新建置

```sh
npm run scr                              # 建置 → release/terminal-sharks.scr，並打包 release/terminal-sharks.zip
node scripts/make-scr.mjs --pack-only    # 不重建，只用現有 .scr 重新打包 zip
```

- `release/terminal-sharks.scr`：自己這台安裝用，路徑固定不動(已安裝的螢保指向它)。
- `release/terminal-sharks.zip`：分享用，內含 `.scr` + `安裝說明.txt`(約 1.9 MB)。說明的原稿在 `docs/安裝說明.txt`，給收檔人看：環境需求、解除封鎖、安裝、快捷鍵、解除安裝、常見問題。

## 給其他電腦用的注意事項

- **Windows**：單一檔案即可(前端已包進 exe，不需要 Node / node_modules)。
  - 傳檔：**Email 多半寄不出去**，Gmail 與公司信箱會擋執行檔，壓成 zip、加密碼的 zip 也常被掃出來。改用雲端硬碟分享連結、LINE 傳檔或 USB。
  - 雲端硬碟：壓成 zip 再上傳(檔名不會被改、也比較不會被當成可疑執行檔)；用個人 Google 帳號上傳(公司 Workspace 常禁止對外分享)，分享設成「知道連結的任何人」。對方下載時 Chrome / Edge 可能警告「不常被下載」→ 選「保留」。解壓**前**先對 zip 做「解除封鎖」，解出來的 `.scr` 就不會帶「來自網路」標記(Windows 內建解壓會把標記傳給解出來的檔案)。
  - 對方安裝步驟：
    1. 先把 `.scr` 放到固定位置(例 `C:\Tools\terminal-sharks.scr`)，不要從 zip 裡直接執行、也不要留在「下載」。「安裝」只記路徑，檔案被搬走或刪掉螢保就失效。
    2. **解除封鎖**：右鍵 →「內容」→ 勾最下面「解除封鎖」→ 確定。沒做的話，閒置自動啟動時 SmartScreen 想跳警告卻顯示不出來，結果是時間到了什麼都沒出現、也沒有錯誤訊息。
    3. 右鍵「測試」確認能跑，再右鍵「安裝」。
  - 對方電腦條件：Windows 10 / 11 且有 WebView2(Win11 內建；Win10 有在更新通常也有；白畫面或沒反應就裝微軟的「WebView2 Runtime」)；x64(ARM 的 Win11 可模擬執行)；公司電腦的防毒或 IT 政策可能直接擋沒簽章的 `.scr`。
  - 沒有程式碼簽章 → 手動執行時 SmartScreen 要按「其他資訊 → 仍要執行」(解除封鎖後就不會跳)。
  - **未驗證**：只在有開發環境的這台測過；在乾淨電腦上是否缺 VC++ runtime 等還沒確認，第一次拿去別台試時記下畫面或錯誤訊息。
- **Mac**：螢保格式是 `.saver`，Tauri 做不出來。選項：
  - A. 把 `dist/` 放 GitHub Pages，Mac 裝開源的 WebViewScreenSaver 填網址(最省事，要連網)。
  - B. 自寫 Swift `.saver` + WKWebView 載入打包的 `dist/`(要在 Mac 上用 Xcode 編譯；新版 macOS 跑第三方螢保有已知怪問題)。
  - 終端機版本來就能在 Mac 跑(`npm start`)。分發給別人要 Apple 開發者帳號簽章 + 公證，否則要右鍵「打開」。

## 宇宙場景：藍咩 + 航星者(像素風)

一開始規劃「側視像素世界」(地面、重力、跳躍)，使用者拿到角色圖後改成**宇宙漂浮**：一隻藍咩和好幾隻航星者在星空裡飄。

### 決定

- 鯊魚海洋維持預設；螢保「設定」(`/c`)可切成宇宙，選擇存在 WebView2 的 `localStorage`(`terminal-sharks.scene`)，設定視窗與螢保視窗同源，所以讀得到。
- 純色像素方塊，約 32 格高；終端機版不支援宇宙場景。
- 藍咩：會眨眼(每 2.5–6 秒閉眼 0.12 秒，兩成機率連眨兩下)。
- 航星者：沒有表情、都有腮紅；飄著飄著隨機變異，**角從帽頂一格一格長出來**(2 → 6 格，每 0.35 秒一階，冒閃光)，長完保持；最多一半會變異。
- 背景：閃爍星星(三層視差，少數十字亮星)、流星(每 8–20 秒)、兩顆遠方行星(一顆有環)。

### 造型(`src/space/sprites.ts`)

格子是「每列一個字串、每個字母一個調色盤顏色」。底稿用 PowerShell `System.Drawing` 把截圖轉成 RGB，再由 Node 縮圖分群；最後逐格手修。和使用者來回修了幾輪，記下看錯的地方：

- 藍咩左上的黑色東西是**鳥嘴面具**(灰色圓是面具的眼睛、往左上伸出的是嘴)，不是貝雷帽。眼睛是直立小橢圓、嘴是一小點。
- 航星者：
  - 嘴在小鏡片正下方，是**玉蜀黍狀的長三角形**，上緣有金點、尖端金色(一開始誤認成眼鏡鍊)
  - 眼鏡**沒有鼻樑**，兩片同高(側 3/4 臉，遠側窄一格)
  - 帽子是**大盤帽**：帽頂扁平比身體寬，靛青帽簷比帽頂短、只往前伸；金色月牙環在帽簷與帽頂交接的後端，下方垂著金點
  - 手是身上一筆彎線；腳是鳥爪，要直接接在下襬下面(空一行就會看起來分開)
- 原圖朝左，格子一律畫朝右，畫面依飄的方向翻面。
- 深色帽子、面具放在夜空上會看不見，面具加了一圈深灰邊。

### 程式

| 檔案 | 內容 |
|---|---|
| `src/space/sprites.ts`(新) | 調色盤、藍咩 2 張、航星者 2 張(下襬與腳交替擺)、`hornGrid(height)` 產生角、`buildSprite()` 轉成 1 倍 canvas |
| `src/space/scene.ts`(新) | `SpaceScene`：`resize/step/render`。藍咩約佔螢幕高 1/6，航星者近層 0.85 倍、遠層 0.55 倍；隨機轉向漂浮、同層互推、上下軟邊界，航星者左右出界從另一邊回來，藍咩留在畫面內；位置對齊各自的像素格 |
| `src/web.ts` | 抽出 `Scene` 介面，鯊魚與宇宙各一個；`?scene=`、`?count=`、`?mutate=fast`；設定頁改成兩個場景選項；新增 `?mode=sprites` 影格檢視頁 |
| `index.html` | 設定頁與影格檢視頁的樣式 |
| `src-tauri/src/main.rs` | 設定視窗加高到 480×260 |

### 怎麼看 / 怎麼調

- `npm run dev` → `http://localhost:5173/?scene=space`；`&mutate=fast` 幾秒內就長角；`&count=6` 指定航星者數量。
- `http://localhost:5173/?mode=sprites` 看所有影格放大 8 倍。
- 改表情 / 造型：直接改 `sprites.ts` 的字母；改速度、眨眼、變異頻率：`scene.ts` 開頭的常數。
- `.scr`：對它按右鍵「設定」選「宇宙」→ 右鍵「測試」。
