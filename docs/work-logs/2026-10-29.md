# 2026-10-29 工作紀錄 — terminal-sharks 做成 Windows 螢幕保護程式(.scr)

原本要開終端機 `npm start` 才看得到鯊魚，實用性不夠。目標：雙擊或閒置就能看，之後能換成自己畫的生物。

## 決策

- 「APK」是 Android 安裝檔，Windows 對應 exe；最後做成 **`.scr` 螢幕保護程式**(`.scr` 就是改副檔名的 exe)。
- 外殼用 **Tauri 2**(Rust + 系統內建 WebView2)，成品約 5.7 MB。不選 Electron(100MB+)、不選「終端機版打包 exe」(仍是主控台視窗)。
- 上游本來就是網頁 canvas：`AsciiRenderer` 直接畫在真的 `<canvas>`，模擬與繪製程式不用改；`term.ts` 的假 context 只是終端機版在用。
- 快捷鍵不寫程式：Windows 捷徑的「快速鍵」欄位指向 `terminal-sharks.scr /s`。
- 換生物：使用者要放自己畫的生物、動作不限於脊椎擺動 → 改用「影格動畫」(見〈後續：換生物〉)，尚未動工。

## 環境(這台電腦)

Node 24.18.1、WebView2 156、Rust 1.99.1(`stable-x86_64-pc-windows-msvc`)、Visual Studio Community 2022(C++ 桌面開發)、Windows SDK 10.0.26100.0。

踩到的點：

- `npm install` 出現 `allow-scripts` 警告(esbuild postinstall 沒跑)→ 無害，執行檔由 `@esbuild/win32-x64` 提供，`esbuild --version` 正常。
- `npx tauri ...` 會卡在 npx 的安裝確認提示 → 改直接跑 `node node_modules/@tauri-apps/cli/tauri.js`(`make-scr.mjs` 已改)。
- 在 Git Bash 用 `$USERPROFILE/.cargo/bin` 加 PATH 會失效(Windows 路徑)→ 用 PowerShell，或新開終端機讓 rustup 設好的 PATH 生效。
- 首次 `cargo check` 24 分鐘、首次 release 建置 24 分鐘(下載並編譯約 400 個 crate、release 開 LTO)；之後只改前端或 `main.rs` 會快很多。

## 如何測試(待做)

1. 瀏覽器版：`npm run dev` → 開 `http://localhost:5173`，鯊魚在游、滑鼠會引誘魚群、點擊濺水花、縮放視窗正常。
2. 終端機版回歸：`npm start`、`npm start -- tiger:dark,mako`，跟改之前一樣；`npm start -- tiger:xxx` 要印出 Unknown shade 並結束。
3. `.scr` 右鍵「測試」：
   - 全螢幕、看得到鯊魚、游標隱藏。
   - 按任一鍵 / 點擊 / 明顯移動滑鼠 → 結束；輕微晃動(<10px)不結束。
   - 多螢幕時每個螢幕都有畫面，任一個螢幕收到輸入就全部結束。
4. 雙擊 `.scr` → 出現「目前沒有設定項目」小視窗。
5. 右鍵「安裝」→ 螢幕保護程式設定已選好它(小預覽框是黑的，預期如此)→ 等待時間設 1 分鐘，放著不動等它自己出現。
6. 捷徑快捷鍵：桌面捷徑目標 `"D:\side\terminal-sharks\release\terminal-sharks.scr" /s`，內容裡設「快速鍵」(例 Ctrl+Alt+S)，按下會直接進螢保。
7. 別台 Windows：只帶 `.scr` 過去(壓成 zip，Email 常擋 `.scr`)，確認 SmartScreen 警告後能跑；最好挑一台沒有開發環境的，順便確認 VC++ runtime 不用另外裝。

關不掉時：Ctrl+Alt+Del → 工作管理員結束 `terminal-sharks.scr`。

若測試失敗，先用開發模式看錯誤：`npm run tauri dev -- -- /s`(會開 Vite 與 debug 版視窗，可在視窗按 F12 開 DevTools)。

## 給其他電腦用的注意事項

- **Windows**：單一檔案即可(前端已包進 exe)。需要 WebView2(Win11 內建；很舊的 Win10 要另裝 WebView2 Runtime)；沒有程式碼簽章 → SmartScreen 要按「其他資訊 → 仍要執行」；x64 版，ARM 的 Win11 可模擬執行。
- **Mac**：螢保格式是 `.saver`，Tauri 做不出來。選項：
  - A. 把 `dist/` 放 GitHub Pages，Mac 裝開源的 WebViewScreenSaver 填網址(最省事，要連網)。
  - B. 自寫 Swift `.saver` + WKWebView 載入打包的 `dist/`(要在 Mac 上用 Xcode 編譯；新版 macOS 跑第三方螢保有已知怪問題)。
  - 終端機版本來就能在 Mac 跑(`npm start`)。分發給別人要 Apple 開發者帳號簽章 + 公證，否則要右鍵「打開」。

## 後續：自己的角色 → 側視像素世界(尚未動工)

方向已改(取代原本「使用者準備影格 PNG、沿用 ASCII 鯊魚質感」的草案)：

- 風格：像馬力歐那種**像素風**，角色是使用者自己的(參考風格，不照抄任天堂的圖)。
- 場景：**整個換成側視的像素世界**(天空、地面、平台、重力、跳躍)，不跟鯊魚海洋混在一起。
- 畫法：**純色像素方塊**(每個像素一個實心色塊，紅白機感)，不填 ASCII 字元。
- 鯊魚海洋保留，成為另一個場景；之後由 `/c` 設定視窗選場景(或隨機)。

### 使用者要提供的

- **一張 JPG** 就好：全身入鏡、背景單純、側面角度。
- 一兩句話描述：怎麼移動、什麼個性(例：慢吞吞愛睡 / 好奇愛跳)。
- 可選：場景偏好(白天 / 夜晚、草地 / 磚塊 / 雲)。

### 角色圖怎麼做(由 Claude 產出)

- Claude 沒有 AI 繪圖工具，但像素圖就是「色號表格」，可以用文字寫出來：每列一個字串，每個字母對應調色盤的一個顏色。
- 先寫小程式把 JPG 縮小(約 16–32 px 高)+ 減到十幾色當底稿，再手動修乾淨，比從零畫更貼近原圖。
- 影格(初版)：站立 + 眨眼 2 張、走路 2–4 張、跳躍 1 張；表情(開心 / 驚訝 / 睡覺)各一張臉部不同的影格。
- 頭朝右畫，往左走時程式水平翻轉。

### 程式改動計畫

- 新場景(例 `src/pixel/`)：tile 地圖(地面、平台)、重力與碰撞、角色狀態機(站立 / 走 / 跳 / 表情)。
- 螢保沒有人操作 → 角色自動行動：隨機走一段、遇到障礙或平台邊緣就跳或轉身、閒置久了切換「睡覺」表情等。
- 繪製：整數倍放大(每個像素 = N 個螢幕像素，依螢幕大小決定)，`imageSmoothingEnabled = false` 保持銳利。
- 沿用：`src/web.ts` 的主迴圈、輸入處理、螢保模式判斷；`src-tauri/` 外殼完全不用改。
- 終端機版(之後可選)：用半格字元 `▀`(前景色 = 上半像素、背景色 = 下半像素)，一個 1:2 的字元剛好畫兩個正方形像素。
- 調整流程：`npm run dev` 在瀏覽器即時看 → 反覆調表情、動作 → 滿意再 `npm run scr` 重建(Rust 相依已編好，不會再等 24 分鐘，但 release 最佳化仍要幾分鐘)。
